FN04 = the EMITTED-functional mandate (ADR 0036) made an ENFORCED build-time arch-fitness guard (after FN02 graved the mandate, FN03 reformed the emitter).

What it does (back/runtime/agentloop/emittedfitness.go):
- `CheckEmittedFunctional(filename, src)` — pure/total, over ONE emitted Go file. Three rules: EMITTED_NO_GLOBAL_MUTABLE (token.VAR at package scope; `var _` blank assertion exempt; const/type ok), EMITTED_FUNCTION_PURE (no-receiver `init()` FuncDecl), EMITTED_CALL_GRAPH_ACYCLIC (three-colour DFS, sorted nodes, over intra-file call graph). Fail-closed: parse error → EMITTED_UNPARSEABLE.
- `IsEmittedProjection(src)` — scope gate on the "CODE GENERATED BY AIDOS" marker. SCOPE DECISION (honest, ADR 0036 §3): binds only emitted OUTPUTS under gen/, NOT emitter logic (e.g. gen/db unmarked, holds legit enum-order var slices) nor sqlc output. Avoids editing another step's code (wall/anti-overwrite).
- `ScanEmittedTree(dir)` — deterministic tree scan; `EmittedInvariantCodes()` single source for config parity.
- MCP tool `agentloop_emitted_fitness` (read-only, default dir back/gen) registered in mcp/agentloop/main.go.
- arch-fitness.json gains `emitted_functional` block; config_test.go pins config↔EmittedInvariantCodes() parity.
- Front twin lib/emitters.ts `checkEmittedFunctional(goSource)` (regex source scan — NOT a Go parser, documented as screen reflection; Go AST walk is authoritative) + EMITTED_INVARIANTS module const (immutable, fine). /emitters panel "CHECK ARCH-FITNESS" button gated to go-sqlc target (data-testid arch-fitness-go-sqlc, verdict data-archfitness).
