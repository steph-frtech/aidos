## Fixture A — emitting an entity across its targets produces a Go (sqlc), a DDL, and a TS projection (one source → N projections)

- state (entity AST):
  - `{ id: "entity-order", kind: "entity", body: <Order: id text, total numeric, discount numeric> }` (read from kernel, S02)
- command (project): `Project([entity-order], ["go-sqlc","pg-ddl","ts-types"])`
- events: `[ Emitted, Emitted, Emitted ]`
  - 3 artifacts returned, one per target
  - each `artifact.source_hash == Hash(Canonicalize(entity-order.body))` (content-addressed, S02 reused)
  - each artifact header contains `"CODE GENERATED BY AIDOS — DO NOT EDIT"` and the source hash (protected)
  - the go-sqlc artifact path ends `back/gen/...`; the ts-types artifact path ends `front/web/...`

## Fixture B — the same source gives byte-identical output (THE done criterion: determinism)

- state (entity AST): `{ id: "entity-order", body: <Order: id, total, discount> }`
- command (emit-twice): `a := Emit(entity-order, "go-sqlc") ; b := Emit(entity-order, "go-sqlc")`
- events: `[ Emitted, Emitted ]`
  - `a.bytes == b.bytes` (byte-for-byte, same machine)
  - `a.output_hash == b.output_hash` (and across a re-run)

## Fixture C — a changed source yields a new output and a new source_hash (no silent drift)

- state (entity AST): `{ id: "entity-order", body: <Order: id, total> }` (discount removed)
- command (project): `Project([entity-order'], ["ts-types"])`
- events: `[ Emitted ]`
  - `artifact.source_hash != <hash of the previous Order body>` (version = hash, S02)
  - the prior artifact remains valid in the ledger (append-only) and is now STALE relative to the new head

## Fixture D — a hand-edited gen/ file is detected as drifted (THE second done criterion: gen/ never hand-edited)

- state (gen): `{ path: "back/gen/order/order.go", bytes: <emitted>, output_hash: H0 }`
- command (tamper): hand-edit the bytes ; re-emit `Emit(entity-order, "go-sqlc")`
- events: `[ Emitted ]`
  - re-emitted `output_hash == H0 != hash(tampered bytes)` (the hand-edit cannot survive a re-emit)
  - the drift is computable (`Drifted(ledger.output_hash, on-disk hash)` is true) — feeds the red wave (S22), not hunted

## Fixture E — an entity field the AST does not pin is never invented (honesty)

- state (entity AST): `{ id: "entity-thin", body: <only: id text> }`
- command (project): `Project([entity-thin], ["go-sqlc"])`
- events: `[ Emitted ]`
  - the artifact emits only the pinned field (`id`); no invented column / field / targetId

## Fixture F — a malformed / empty entity AST yields a BlockReason, never a panic, never an invented field

- state (entity AST): `{ id: "entity-broken", body: <no fields> }`
- command (project): `Project([entity-broken], ["go-sqlc"])`
- events: `[ Blocked ]`
  - a `BlockReason` is returned (not a panic, not an artifact, not an invented field)
