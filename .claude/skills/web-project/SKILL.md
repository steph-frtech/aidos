# /web-project — the web-projection gesture (S38)

A **web projection** is a deterministic **emitter** — the `ts-next` **target** for
`kind=control` inside the **S34 emitter set** (NOT a fork). It **reads** a control-spec
(S11: `{view, label, visible_when, enabled_when, triggers}`) + the action-spec it binds
(S11: `{on:click, invoke, on_success, on_error}`) — both **prior Kernel truth, SELECT-only
(the wall)** — and **emits** a real Next.js client component into
`front/web/app/web-preview/_generated/<control>.tsx`.

**One source → N projections, never double-typed** (KRD LIVRE V). The button you click in
a browser is a **projection** of the control-spec, never hand-authored UI behaviour.

## The procedure (replay this)

1. **Resolve the refs** from `kernel` (SELECT-only): the control by name, and the action
   its `triggers` names. Never invent a `view`, `label`, `triggers`, `targetId`, an
   `invoke`/`version`, or any business rule the AST does not pin — an unpinned field is an
   **OpenQuestion** in `provenance`, never a guessed default.
2. **Emit** the `.tsx` via `back/runtime/generators/webcomponent.Emit(control, action,
   "ts-next")`. The artifact carries:
   - the **protected header** `// CODE GENERATED BY AIDOS — DO NOT EDIT. source: <hash>`;
   - `source_hash = Hash(Canonicalize(control.body ⊕ action.body))` — **reuse S02 + S11**,
     never fork the hashing path;
   - `output_hash` = the digest of the bytes (the byte-identical re-emit proof).
3. **Materialize** the bytes to `_generated/<control>.tsx` (the disk copy is derived;
   `_generated/` is **never hand-edited** — CLAUDE.md §4/§9).
4. **Record the ledger row** via the `aidos` writer role: `runtime.generated_artifacts`
   with `target='ts-next'`, `kind='control'` (append-only; the agent is SELECT-only here —
   the wall).
5. **Verify the fixture**: replay the S11 control-spec state fixture (`given →
   {visible,enabled}`) and the action event fixture (`click → invoke`) against the
   **rendered** component on `/web-preview` (the playwright-bdd e2e
   `tests/e2e/web-preview.spec.ts`). Green e2e = done.

## The determinism contract (S34)

`Emit(c,a)` is a **pure function** of `Canonicalize(c.body ⊕ a.body)` — no clock, no RNG,
no map-order leak, no absolute paths; stable key ordering, normalized `\n` newlines. So
**re-emitting reproduces byte-identical output**. A non-deterministic web emitter is a
**defect**, not an artifact. The component embeds the control's two Expr ASTs and
evaluates them with the shared `lib/aidos-expr` twin (the closed catalogue `>`, `length`,
`&&`, `!`) — the **same semantics as `back/kernel/expr` + `control.EvalState`**, never
re-invented. The TS twin `lib/web-projection.ts` is **byte-identical** to the Go emitter
(anchored on the Go source/output hashes by `lib/web-projection.test.ts`).

## Honesty + the wall

- The control/action specs are **prior truth (S11), read-only** — this gesture **authors
  no new truth**.
- A control whose `triggers` does not resolve to the bound action, or an action whose `on`
  is not a click on this control ⇒ a **BlockReason** (S13 shape, non-empty French
  `how_to_fix`), never a panic, never an invented bind.
- The click **declares** the bound operation (`data-aidos-invoke` = `Plan(action,
  click).invoke`) as a testable signal — it does **NOT execute** the operation (a later
  tooth).
- **Staleness is computed** (`source_hash` ≠ the control's head feeds S22's red wave),
  never hunted.
- Targets beyond `ts-next` and controls beyond the button grow the matrix **additively** —
  never invented in passing.
