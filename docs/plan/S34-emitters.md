# S34 — Emitters (one per kind × target: deterministic, hash + protected codegen)

Subsystem: AIDOS Runtime | Home: `back/runtime/generators` | Workbench route: `/emitters`

## Objectif

Land the **emitters** of KRD's N3 contracts line (the frozen stack row "entities = AST in Postgres (JSONB) → emit Go structs (sqlc), Postgres DDL, TS types"): a set of **deterministic generators, one per `kind × target`** (entity × {go-sqlc, pg-ddl, ts-types}), that read an entity AST from the `kernel` schema and emit its projection into `back/gen/` (Go) and `front/web/` (TS) — **never double-typed**, one source → N projections (CONTEXT-MAP "Kernel → projections: constrains, never generates"). Determinism is the contract: the **same source gives byte-identical output**, the emitted artifact carries its **source content-hash** so staleness is computable, and `gen/` is **protected** — never hand-edited (CLAUDE.md §4 "code generated by emitters … NEVER hand-edited", §9 "hand-editing generated files" forbidden).

## Sortie attendue

Per CLAUDE.md §5 this step needs **pure logic/schema** (a Go package), **persistence** (an Atlas migration for the emit ledger), a **repeatable gesture** (the `/project` Skill), a **behaviour proof** (the BDD mirror), and a **visualization** (a Next route) — and nothing more:

- **Go package** `back/runtime/generators/` — the emitter set per KRD's N3 contracts line and the Runtime CONTEXT "generator (emitter)" term ("a deterministic emitter, one per `kind × target`, that produces a projection from a source"). The typed `Emitter` shape: `kind` (currently `entity` — the N3 contract AST from S02's records, **read** from `kernel`, never authored here), `target` (`go-sqlc | pg-ddl | ts-types`), and a pure `Emit(source) → Artifact`. The `Artifact` shape: `path` (where the projection lands — `back/gen/...` for Go/DDL, `front/web/...` for TS), `bytes` (the rendered text), `source_hash` (the content address of the entity AST it was emitted from — reuse S02's `Canonicalize`/`Hash`, do **not** fork it), and a `protected: true` marker stamped into the file header (`// CODE GENERATED BY AIDOS — DO NOT EDIT. source: <hash>`). A pure `Project(sources, targets) → []Artifact | BlockReason` fans one entity out across its targets. **Determinism is the central invariant**: `Emit` is a pure function of `Canonicalize(source)` — no clock, no RNG, no map-iteration-order leakage, no absolute paths — so `Emit(s)` byte-for-byte equals `Emit(s)` on every run and on every machine (stable key ordering, fixed import order, normalized newlines). The emitters **call sqlc** as the frozen Go-DB-access tool to turn entity → typed Go (sqlc is mandatory, never substituted); the DDL and TS emitters render from the same AST so the three projections can never drift from each other. No truth is written: an emitter only **reads** the entity AST (SELECT-only on `kernel`) and **writes projections** into `gen/` / `front/web/` — below the wall (§2).

- **Atlas migration** (`back/migrations/`) — one declarative, expand-only migration adding the **emit ledger** table `runtime.generated_artifacts`: `path text NOT NULL`, `target text NOT NULL CHECK (target IN ('go-sqlc','pg-ddl','ts-types'))`, `kind text NOT NULL` (currently `'entity'`), `source_hash text NOT NULL` (the entity AST content address it was emitted from), `output_hash text NOT NULL` (the content hash of the emitted bytes — proves byte-identical re-emission), `emitted_at timestamptz NOT NULL`, `PRIMARY KEY (path, source_hash)`. The ledger lets staleness be **computed** (an artifact whose `source_hash` no longer matches its entity's current head is stale — it feeds the red wave, never hunted). GRANTs: the agent DB role gets **SELECT only** on `kernel.*` (it reads the entity AST, never authors it — the wall, §2) and SELECT on `runtime.generated_artifacts`; only the `aidos` CLI writer role inserts ledger rows. The migration is **append-only / expand-only** and never alters or drops a prior table or GRANT.

- **Skill** `.claude/skills/project/` (`SKILL.md`, CLAUDE.md §5: repeatable gesture → Skill) — `/project`: the replayable gesture "emit the projections for an entity across its targets" (the `/project` skill named in the Runtime CONTEXT skill list). It encodes the procedure (take entity refs from `kernel` → `Project(sources, targets)` → write artifacts into `gen/` / `front/web/` with the protected header → record the emit ledger via the writer role → never hand-edit `gen/`), the **determinism contract** (re-emitting the same source must reproduce byte-identical output; a non-deterministic emitter is a defect, not an artifact), and the **honesty rules** (never invent a target or a targetId; an entity field the AST does not pin is not invented — it becomes an OpenQuestion in `provenance`). It is the harness command form of "one source → N projections, never double-typed".

- **BDD mirror** — a **fixture** mirror (`state → command → events`: an entity AST → `Project` → the three artifacts, each carrying its source hash) plus a **`rapid` property** mirror for the ∀ determinism invariants, conceptually stored in the `mirrors` schema and materialized to `tests/` for the Go runner. **Testcontainers (Go)** with real Postgres applies the Atlas migration so the emit-ledger round-trip is verified end-to-end, not mocked. These ARE the done criteria (see below).

- **Next route** `front/web/app/emitters/` → `/emitters` — the Workbench panel rendering, per entity, the three emitted projections (go-sqlc · pg-ddl · ts-types), each with its `source_hash`, its `output_hash`, a **deterministic / stale** badge (source hash matches current entity head?), and a read-only view of the protected header (see "Visualisation UI").

> Explicitly **out of scope** (would be monsters / out of slot here): **no MCP server** — `Emit`/`Project` are a pure library and `/project` is a harness gesture; the emitters do not yet warrant a *distinct* callable backend service (if a callable `project_emit` op truly emerges, record an OpenQuestion). **No hook** — `gen/`-protection is already covered: the wall hook (S04) refuses agent writes above the line, and hand-editing `gen/` is caught by re-emit byte-equality + the PostToolUse sensors; this step adds **no** new non-bypassable rule (and §5 hook-honesty forbids a hook that never fired). **No entity/DSL AST authoring** — the `entity` AST is a prior truth (S02 records); here an emitter **reads** it and adds only the projection + ledger; defining new entity kinds is not this step. **No new ChangeSet/SemanticDiff machinery** (S20/S21, consumed if a prior contract is touched). **No red-wave/impact computation** — S22 owns the cascade; a stale `source_hash` *feeds* it, it does not re-implement it. **No targets beyond go-sqlc / pg-ddl / ts-types** — mobile/api/other emitters are later teeth (the kind × target matrix grows additively); do not pre-build them.

  ```
  fixture "a hand-edited gen/ file is detected as drifted (gen/ is never hand-edited)"    # THE second done criterion
    state   (gen):        { path: "back/gen/order.go", bytes: <emitted>, output_hash: H0 }
    command (tamper):     hand-edit back/gen/order.go ; re-emit Emit(entity-order,"go-sqlc")
    events:  [ Emitted ]
    -> re-emitted output_hash == H0 != hash(tampered bytes)                              # the hand-edit cannot survive a re-emit

  fixture "an entity field the AST does not pin is never invented"                        # honesty
    state   (entity):     { id: "entity-thin", body: <only: id> }
    command (project):    Project([entity-thin], ["go-sqlc"])

  ```

- **Invariant (∀) — `rapid` property test (Go), below the line, computational:**

  ```
  # reflects: runtime.generators.{Emit,Project} · test_kind: property · cert_language: rapid · authority: below
  ∀ entity AST e, target t:           Emit(e,t) == Emit(e,t)                  — determinism (same source ⇒ byte-identical, no clock/RNG/map-order)
  ∀ entity AST e, target t:           Emit(e,t).source_hash == Hash(Canonicalize(e.body))   — content-addressed source (S02 reused)
  ∀ entity AST e, target t:           Emit(e,t).bytes starts with the protected header carrying source_hash   — gen/ is marked protected
  ∀ entities es, perm(es):            Project(es,…) is order-independent per artifact (stable output regardless of input order)
  ∀ entity AST e:                     the same e ⇒ identical Go, DDL, TS that agree on every field (never double-typed, no inter-target drift)
  ∀ entity AST e, e':  e.body != e'.body ⇒ Emit(e,t).source_hash != Emit(e',t).source_hash   — a changed source never silently keeps the old hash
  ∀ malformed/empty entity AST:       Emit/Project yields a BlockReason — never a panic, never an invented field
  ```

Both start **red** (no `generators` package, no `Emit`/`Project`, no `runtime.generated_artifacts` table, no `/project` skill). That red **is** the meta-`/goal` for this step. The fixtures are **means-tests toward the human red** (same source ⇒ byte-identical output; `gen/` never hand-edited) — **not** new truths the agent invents and then grades. The agent never authors the entity AST it emits from (the wall); it only proves the projection is a faithful, deterministic, marked-protected function of that source.

## Regle anti-ecrasement

This step **edits only its own declared files** — `back/runtime/generators/**`, the new `back/migrations/<new>.sql`, the generated outputs under `back/gen/**` and the emitted TS under `front/web/**` (written **only** by the emitters, never hand-edited), the new `.claude/skills/project/SKILL.md`, the `mirrors`-stored fixture/property materialized to `tests/`, `tests/e2e/emitters.spec.ts`, and `front/web/app/emitters/**` — and otherwise **adds new files**. It defines one new contract (the `Emitter`/`Artifact` shape, `Emit`/`Project`, the determinism + protected-header rule, the `runtime.generated_artifacts` ledger, the `/project` skill); it changes none. Per CLAUDE.md §9: **no hand-edit of generated files** (`back/gen/**`, emitted `front/web/**` — the whole point of this step), no rewrite of a prior artifact, no silent model replacement, no touching prior Workbench routes. The migration is **expand-only / append-only** and never alters or drops a prior table or GRANT. Any change to a **prior contract** it depends on — S02's record/entity AST shape and `Canonicalize`/`Hash`, the `kernel` schema's entity rows, S04's wall GRANT set, S13's `BlockReason` shape, S22's red-wave staleness consumer, the sqlc config — goes through a **ChangeSet** (`DRAFT → APPLIED`, completeness-gated) plus a **SemanticDiff** on the affected schema/mirror, never an in-place edit. A re-emit that would change a published projection's bytes is itself driven by a *source* change (a kernel ChangeSet), never by editing `gen/`. An override is a recorded decision (ChangeSet + ADR + provenance), not an edit. A new artifact may **ADD** a guardrail, never **REMOVE** one (§5 meta-loop rule).
