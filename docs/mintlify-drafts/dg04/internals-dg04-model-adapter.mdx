## Implémentation

**Le seam `ModelAdapter` (`back/runtime/requirementbench/adapter_dg04.go`)** — l'injectable « modèle » derrière le port DG02 :

```go
type ModelAdapter interface {
    Propose(spec Spec) ([]LLMOutput, error) // total, jamais panique
    Available() bool                        // produit-il sans fallback ?
    Name() string                           // identité opaque — le rapport en est invariant
}
```

**`BenchVia(adapter, spec) → (CompletenessMetric, Provenance)`** est le cœur *determinism-first* de DG04. Il appelle l'adapter, **PUIS re-juge TOUJOURS** sa sortie par la fonction pure DG03 (`Metric`, qui réutilise `Derive`/`Extract`). Le modèle **propose** du texte, le juge déterministe **compte** les types — le juge **domine**. Dégradation gouvernée : adapter indisponible **OU** `Propose` en erreur **OU** zéro candidate ⇒ fallback `RecompileProjection` (le « recompile seul »), **jamais** une erreur d'écran. `usedRealLLM` est reporté honnêtement via une interface privée `realLLMReporter` (dispatch `adapterUsedRealLLM`) — un adapter qui n'opte pas est déterministe (false par défaut).

**`FixtureModel`** — l'adapter déterministe **sans réseau**, le modèle du **miroir hermétique**. `Propose` dérive **purement** trois candidates de la spec : `single` (`lensSingle`, la projection happy-path littérale), `A` (`lensUX`), `B` (`lensFormal`). Les trois `lens` **partitionnent la taxonomie close** (les 22 `RequirementKind` du port) : `lensUX` surface les facettes user-facing (visible/enabled, on_success/on_error, empty_state, error case), `lensFormal` les facettes transverses (invariant ∀, policy, budget, guard, event, edge case) — **complémentaires**, ce qui rend le surplus différentiel **réel**. `lensTaggedText(spec, lens)` n'émet une ligne taguée que pour les `ExpectedKinds` de la spec **que la lentille surface** (le mur : le modèle propose **dans** la structure déclarée par l'humain, il ne l'invente pas), dans l'ordre canonique de la taxonomie → texte **byte-stable**.

**`ClaudeModel`** — l'adapter **réel** (l'exception gatée). Il shell vers `claude --print --model <model>` (`model = AIDOS_LLM_MODEL` ou `claude-opus-4-8` ; binaire `AIDOS_CLAUDE_BIN` ou `/home/stevig/.local/bin/claude`) avec **trois rôles** : `single` (re-state littéral), `A` (lentille UX), `B` (lentille formelle) — **deux lentilles de prompt comme deux « modèles »** pour le différentiel + la baseline. `Available()` **sonde le binaire** (`os.Stat`/`exec.LookPath`) — le pré-flight bon marché qui laisse `BenchVia` retomber **sans** un exec échoué quand le modèle est simplement absent. Toute erreur (timeout, binaire absent, `errExecUnavailable`) ⇒ `Propose` rend l'erreur, `BenchVia` retombe ; succès ⇒ `calledReal=true`, `usedRealLLM()` honnête. `rolePrompt` impose la **même** grammaire de marqueurs close que `Extract` parse — la LLM propose des lignes taguées, le juge pur compte les types.

**`Provenance{ModelName, UsedRealLLM, FellBack}`** — l'audit déterministe et **honnête** de l'exception gatée (zéro score, écrit rien) : la Workbench (DG06) montrera « IA échantillonnée » vs « recompile seul » sans mentir.

## Méta

Le miroir n'est pas un test ajouté : c'est le **done-criterion**, **rouge d'abord** et **hermétique** (tout tourne sur `FixtureModel`, zéro réseau). Quatre propriétés ∀ (`adapter_dg04_property_test.go`, rapid) cartographient exactement les critères de done DG04 :

1. **`TestJudgeDominatesModelIdentity`** — deux adapters **différents** (`FixtureModel` et un `staticModel`) émettant les **mêmes** sorties donnent le **même** rapport (`reflect.DeepEqual`), et ce rapport **égale la `Metric` pure** sur les mêmes candidates. Le juge domine l'identité.
2. **`TestModelAbsentGovernedFallback`** — un `brokenModel` (Available=false, Propose en erreur) ⇒ `FellBack=true`, `UsedRealLLM=false`, le rapport **égale** la métrique recompile-only, `MatchPct ∈ [0,1]` (jamais NaN). Jamais une erreur d'écran.
3. **`TestAIOffReplayStaysGreen`** — `FixtureModel` rejoué **100×** : rapport byte-pour-byte identique, `UsedRealLLM=false`. Le rejeu reste vert sans IA.
4. **`TestJudgeDeterminismIntact`** — `BenchVia == Metric` sur les mêmes candidates, et **aucun** type présent du rapport n'est cru sans que `Extract` ne le re-surface (le juge n'est jamais court-circuité).

Le fixture `adapter_dg04_fixture_test.go` ajoute le **surplus différentiel** prouvé hermétiquement (l'union A+B récupère ≥1 facette transverse que le recompile seul rate) et la voie réelle **opt-in** (`AIDOS_DG04_REAL=1`) : un échantillon `claude-opus-4-8` re-jugé par la métrique pure, `usedRealLLM=true` câblé avec **skip honnête** si le binaire manque — par défaut le test prouve le **fallback gouverné** (binaire bidon → recompile-only, sans réseau). Échantillon réel observé : `usedRealLLM=true matchPct=1.00 missing=[]` (217 s, trois appels) — le vrai modèle, re-jugé déterministe, couvre la spec démo.

## Méta-méta

DG04 est l'application la plus littérale de **§8 — « le juge est déterministe »** à un branchement de LLM. Tout le monde brancherait le modèle *en juge* (« demande au LLM si la spec est complète ») ; AIDOS l'en **sort** et le confine à **proposer** du texte derrière un seam, **toujours** re-jugé par une fonction pure. C'est *determinism-first* (§6) tenu à la lettre : la LLM est l'**exception gatée**, isolée à la plus petite surface (`ClaudeModel.Propose`), et la garantie repose sur le chemin **pur** (le `fixtureModel`, le miroir hermétique) — l'IA éteinte, le rejeu reste vert. C'est le **mur** (§2) : `BenchVia` rend une **valeur** ; les `MissingTypes` proposés rejoignent le kernel **uniquement** par `firewall.ViaIdea → idée → miroir → /goal`, jamais `ToKernel`. C'est **model-agnostic** par construction (§9, additif) : le vrai DiffusionGemma — diffusion, poids/GPU non garantis ici — se branchera comme **un adapter de plus** derrière ce même port, re-jugé par cette même métrique ; la dépendance infra est **documentée**, pas bloquante. Et l'oracle déterministe de la complétude (ADR 0072) reste **autoritaire** : le bench **propose** des trous, il ne **gouverne** jamais la fermeture d'un goal.
