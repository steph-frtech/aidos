## Implémentation

**Le twin pur `front/web/lib/v3/evolve-view.ts`** — la projection `(cellule, générateur, budget, graine) → CellRun`, **byte-cohérent** avec le Go `back/runtime/evolve` (la référence). Chaque dérivation rejoue **verbatim** son homologue Go :

- **`splitmix64`** (le PRNG seedé de `proposers.go`) — réécrit en **BigInt** (JS n'a pas d'entier 64 bits natif), masqué à chaque pas (`& U64`). Détail de portage : la cible `tsconfig` est **ES2017**, donc **aucun littéral `n`** — les constantes passent par `BigInt("0x…")` / `BigInt(30)`. Vérifié : le flux `0.1 + 0.85*float01()` produit, graine 42, **exactement** les mutations du Go (`0.235924, 0.336811, 0.392562, …`).
- **`deriveMirror(m)`** — `m > 0.85 → "red"` sinon `"green"` (`selfplay.go`). **`deriveOutOfSampleValue(m)`** — `1 - 0.6*m`, borné `[0,1]`. **`deriveOutOfSample(cell, m)`** — vert ssi `≥ cell.outOfSampleThreshold` (§87). **`deriveFitness(m)`** — `0.5 + 0.3*m*oos` (diagnostique, ordonne, ne surcharge **jamais** le gate).
- **`promote(row)`** — le gate binaire (`evolve.go`) : `mirror→oos→authority`, **dans cet ordre** (le premier échec donne le motif, byte-cohérent avec l'ordre des `if` du Go). Une variante au miroir rouge est refusée **quel que soit** son score.
- **`fixturePropose(cell, budget, seed)`** — le **self-play seedé** (`FixtureProposer`) : `proposalCount(budget)` candidats (borné `[5,8]`) en round-robin sur les niches **déclarées**, mutation `0.1 + 0.85*float01()`. **`deterministicPropose(cell)`** — le **`FallbackSampler`** : une seule variante `<cell>/baseline`, mutation 0.3 (miroir+oos verts) mais niche **non approuvée** par l'autorité → refusée sur la condition d'autorité.
- **`projectCellRun`** — assemble : trie les propositions `(niche, mutation)` (l'ordre rejouable du Go), juge chacune (`judge → VariantRow`), agrège les `nichesWon` (gate passé, distinctes, triées) et la `coverage` (= `NicheCoverage` du Go). **PURE, totale, déterministe.**

Le **jeu canonique hermétique** est déclaré (`CANONICAL_CELL` : 3 niches, 2 approuvées, plancher oos 0.55 ; `CANONICAL_SEED=42`, `CANONICAL_BUDGET=8`) — c'est ce que `runCanonical(sampler)` rejoue, sans réseau.

**La route `front/web/app/v3/evolve/`** — `page.tsx` (serveur : titre + intro via `getTranslations`) + `EvolveClient.tsx` (client : sélecteur de générateur, la table des variantes avec pastilles miroir/oos + badge de verdict, les niches gagnées + la couverture, et le bouton « Lancer une exploration » qui **`send`** un geste canonique). Tout vient de `useV3Session` (les `strings` i18n injectés par le layout, le `send` partagé) ; **aucune** logique de dérivation re-implémentée à l'écran — il **projette** `runCanonical`. Themed (tokens shadcn ADR 0010, jamais de `zinc-*`/hex en dur) + bilingue (ADR 0011).

**La nav `app/v3/V3Nav.tsx`** — une entrée ajoutée à `ENTRIES` (`/v3/evolve`, clé `navEvolve`, icône `Dna`) **sans toucher** les autres (additif, §9). **L'i18n** — 33 clés `evolve*` + `navEvolve` ajoutées à `messages/fr.json` **et** `messages/en.json` (FR d'abord, parité 33/33), et au tableau `KEYS` du layout (un client ne peut pas appeler `getTranslations`).

## Méta

Le miroir est le **done-criterion**, écrit avant l'écran et **hermétique** : `front/web/lib/v3/evolve-view.test.ts` (**fast-check**, 19 tests verts). Il cartographie les garanties :

1. **Byte-cohérence avec le Go** — le run self-play canonique reproduit **exactement** le flux seedé (les 8 mutations Go, graine 42, triées) ; les niches gagnées sont `{discount, refund}` → couverture **2** ; la niche non approuvée (`split`) ne gagne **jamais** (refus *authority*) ; la variante oos-rouge (`mutation 0.837994`) est refusée sur *oos*, pas sur *authority*.
2. **Le sampler déterministe** — une variante `baseline`, refusée *authority*, **0** niche gagnée → le self-play **out-couvre** le déterministe (le gain EG04 rendu mesurable).
3. **Le gate anti-Goodhart** — l'ordre des motifs (`mirror→oos→authority`) ; ∀ : un miroir rouge n'est **jamais** promu, quel que soit le reste.
4. **Le déterminisme (le miroir de reproductibilité, §6/§8)** — ∀ (cellule, générateur, budget, graine) : `projectCellRun` est **byte-identique** d'un appel à l'autre ; une niche gagnée a **toujours** une variante au gate passé (jamais inventée) ; le générateur n'émet **que** des niches **déclarées** (honnêteté §8) ; un gate passé ⟺ miroir vert ∧ oos vert ∧ autorité.

**Le Playwright e2e** `tests/e2e/eg05-evolve.spec.ts` (port **3210**, jamais :3000 ; **IA coupée** d'abord — la bascule `v3-ai-toggle`, défaut ON prouvé) : la nav offre la lentille ; la table rend **8 variantes** chacune avec un **verdict** (≥1 promue, ≥1 refusée) ; la couverture self-play vaut **2** ; le générateur déterministe rend **1** variante refusée et **0** niche ; le bouton « Lancer une exploration » fait apparaître l'indicateur d'envoi (`v3-evolve-launched`) **et** une carte assistant au lab (le transcript a grandi — la preuve que `send()` a traversé le réducteur, **ui-completeness §6/§7**).

## Méta-méta

EG05 est **purement additif** (§9) : il n'ajoute **rien** au moteur `back/runtime/evolve` (le seam, le self-play, les générateurs, le gate sont **inchangés**) — il en **projette** le comportement dans une lentille. La règle structurante est la **déterminisme-first** poussée à l'écran : *tout ce qui peut être une fonction pure l'est*, et **c'est elle qui fait autorité**. Le twin n'est pas une « ré-implémentation côté front » qui pourrait dériver : c'est une **projection re-vérifiée** dont le miroir fast-check prouve la **byte-cohérence** avec le Go (mutations graine 42, ordre des motifs, gate à trois conditions). Si le moteur change une dérivation, le miroir du twin **rougit** — le twin ne peut pas mentir en silence.

Le **mur (§2)** est tenu par construction : la lentille n'a qu'**un** geste d'écriture, un message de chat (`send`) qui repasse par le réducteur ; **aucune** écriture `kernel/mirrors/fitness`. Une **promotion** reste une **proposition** — le gel est le **`/goal` humain** (`firewall.ViaIdea → idée → miroir → approbation`). Et l'**exception LLM gatée** (le vrai `ClaudeProposer`) reste **côté Go, derrière le seam** : elle ne descend jamais dans l'écran, qui rejoue un run **seedé/hermétique**. L'écran montre le générateur **à l'œuvre** sans jamais devenir un chemin par lequel l'IA écrirait une vérité.
